# NovaBook Pro — Responsive Product Landing Page

A responsive laptop product landing page built for the **Web Development – Week 02 Minor Project**.

## Project overview
NovaBook Pro is a fictional laptop brand used to demonstrate a modern product landing page. The page includes all seven sections listed in the project brief:

1. Navigation bar
2. Hero section
3. Features section
4. Benefits section
5. Testimonials / reviews
6. Pricing / call to action
7. Footer

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive media queries

This version uses plain HTML and CSS only. It does not use JavaScript, Tailwind CSS, or any other framework.

## Files
```text
novabook-laptop-landing-page/
├── index.html
├── style.css
└── README.md
```

## How to run
1. Download or clone this project.
2. Keep `index.html`, `style.css`, and `README.md` in the same folder.
3. Open `index.html` in a browser.
4. For easier development, open the folder in VS Code and use the Live Server extension if installed.

## Images
The page uses remote images from Unsplash. An internet connection is required to load these images. You may replace the image URLs in `index.html` with your own images.

## Customisation
- Change the product name and copy in `index.html`.
- Adjust colours and layout in `style.css`, starting with the CSS variables under `:root`.
- Update the sample price and product specifications before presenting if you want to use different illustrative details.
- The price/specifications and testimonials are fictional examples for this educational project; they are not verified product claims or customer reviews.

## GitHub submission
1. Create a new repository on GitHub, for example `novabook-responsive-landing-page`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Check that the README is visible and the files are organised.
4. Copy the repository URL and submit it through the project submission form on your learning platform.

## Project note
This is a front-end demonstration only. The enquiry button opens an email draft; there is no shopping cart, checkout, or backend.
